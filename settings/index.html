    MQTT

    The SMARWI publishes its status to an MQTT broker and listens there for commands. Unlike the HTTP cloud API this carries the state as well, so a window on another network still reports back. Leave it off if all your devices are on Homey's own network — the local connection already does everything.

    The factory broker is broker.vektiva.com and it accepts your Remote ID and Remote KEY. Point this at your own broker if you run one — the address has to match the one in the SMARWI under Settings → Advanced.

    The MQTT password, found in the SMARWI under Settings → Basic. Leave it empty to reuse the API key above, which is often the same value.
